# Smartkédex

Smartkédex è la tua app Pokédex personale per Android!
Include le descrizioni ufficiali di tutti i 151 Pokémon di prima generazione e la lettura tramite Text-to-Speech (TTS).

## Caratteristiche principali
- Navigazione di tutti i 151 Pokémon con descrizioni ufficiali.
- Sintesi vocale (TTS) per descrizioni e presentazione dell'app.
- Schermata di benvenuto e login con database SQLite locale.
- Integrazione "Pokémon GO": registra quante copie di ogni Pokémon possiedi.
- Gestione e modifica dei dettagli dei Pokémon catturati (nome personalizzato, attacchi, statistiche IV).
- Schermata Impostazioni: imposta il nome dello Smartkédex, nome proprietario e abilita/disabilita l'integrazione Pokémon GO.
- My Pokémon Details: visualizza e modifica copie multiple, attacchi, ultimative, IV e nomi personalizzati.
- Swipe nei dettagli Pokémon per passare al precedente o successivo.
- Layout responsive ottimizzato per diverse densità DPI e formati di schermo.
- Sincronizzazione asincrona con web service per backup e ripristino dei dati.

## Requisiti e installazione
1. Clona questo repository:
   ```bash
   git clone https://github.com/TheFe91/Smartkedex.git
   ```
2. Apri il progetto in Android Studio (versione 3.x o superiore).
3. Compila e installa su un dispositivo o emulatore Android (min SDK 19, target SDK 27+).
4. Concedi i permessi per Text-to-Speech e accesso alla rete per la sincronizzazione.
